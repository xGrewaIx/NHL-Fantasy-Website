# NHL Fantasy Platform

An end-to-end NHL data engineering, analytics, and fantasy hockey platform.

The project will eventually include:

- NHL data ingestion
- Bronze / Silver / Gold data architecture
- xG modeling
- Player and team analytics
- Fantasy rankings
- Trade analysis
- FastAPI backend
- Streamlit frontend
- PostgreSQL analytical warehouse
- AWS data pipeline
